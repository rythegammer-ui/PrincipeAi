# Profile setup kit

> **What this file is:** the step-by-step setup for every Principe AI social profile, in priority order. For each platform you get the account type, handle, name, bio, links, pinned posts, images, settings, verification steps and a "done when" check.
>
> **When to use it:** in the Setup phase, L-21 (Tue Oct 20) to L-8 (Mon Nov 2). Tier 1 comes first. Come back on launch day, L+0 (Tue Nov 10), to pin the launch posts.
>
> **How to read it:** text in a grey box is ready to paste. A script made every link and every character count. Post IDs (LD-, SV-, TP-, VC-, LC-, CB-) point to the post kits listed in the [README](README.md). Dates are given as L-days (L = launch day) with the default date next to them, so you can move the whole plan. The day-by-day plan is in the [launch calendar](02-launch-calendar.md).

**How sure each fact is.** **Checked** means the platform's own help pages say so (October 2026). **Reported** means several third-party guides agree. **Check in the app** means nobody could confirm it, so look at the screen before you rely on it.

## 2. Rules for every profile

### 2.1 Names and handles

- **Handle:** `@principeai` everywhere. If it's taken, use the fallbacks for that platform in section 3: `@principe.ai` where periods are allowed, then `@principe_ai`, then `@getprincipeai`. Write down every handle you end up with.
- **Display name:** it always starts with **Principe AI**, spelled exactly like that. Where the name field is used by in-app search (Instagram, TikTok, X and Pinterest), add one keyword phrase after a bar, such as `Principe AI | AI Tips & Tools`. On YouTube, LinkedIn, Facebook and Bluesky, the name is just `Principe AI`, because those fields should be the business name.
- **Settle names early.** Several platforms limit changes. YouTube allows two name and handle changes in 14 days (checked). TikTok and Instagram limit changes too (reported). Paid checkmarks on X disappear when you change your name or photo (checked).

### 2.2 Links

- **The main profile link always goes to the bio page**, `principeai.com/links`, tagged with that platform's `utm_source`. The page lists the Starter Kit, the assessment, the courses, the strategy call and implementation. The tag sets a 90-day first-touch cookie, so Admin → Funnels credits every lead from that bio to the right platform.
- **Where a platform allows more than one link,** the extras go straight to `/free-guide`, `/assessment`, a free preview lesson and `/courses` (and `/book/ai-strategy-call` on YouTube and LinkedIn).
- **Every profile link uses `utm_campaign=evergreen`**, including Highlights and DM automations. `utm_medium` is `bio` for profile links and buttons, and `dm` for messages.
- **DM replies you send by hand** outside the three keywords (KIT, READY, WORKFLOW) use `utm_medium=dm`, `utm_campaign=evergreen` and, as `utm_content`, `dm-call` or `dm-courses` for general call or course questions, or the ID of the post they reply to (such as `tp-07`).
- **`/links` exists only once the website branch is merged** (7.3, done on L-20 before any bio link). If it isn't live yet, use the temporary main link in the [launch calendar](02-launch-calendar.md) (L-20) and swap it on L-12.
- **Copy links from section 8. Never retype them.** One wrong letter in `utm_source` creates a new row in Admin → Funnels.
- **Starter Kit links always go to `/free-guide`, never `/guide`.** Never link a private page: `/assessment/results/…`, `/booking/…` or `/book/confirmed/…`.
- Links between your own profiles (for example, Instagram listed on YouTube) carry no UTM tags.

### 2.3 Words

- Every character count in this file includes placeholders as written (`[YOUR NAME]` counts as 11). Recount after you fill them in.
- Confident, warm, plain English. No hype words, no numbers you can't prove, no testimonials (there are none yet), no credentials or story you haven't written yourself. Keep `[YOUR NAME]`, `[YOUR STORY: …]` and `[YOUR CREDENTIAL IF ANY]` as placeholders until you fill them with true details. If you have nothing true to put in one, delete the whole line.
- Name the tools as "AI assistants like Claude, ChatGPT and Gemini", in plain text. No logos of any AI company on any image.
- In About and description sections, where it fits, add this exact line: **"Principe AI is independent and not affiliated with Anthropic, OpenAI or Google."** Short bios don't need it.
- **No prices in profiles.** Prices change in Admin → Courses.
- **No profile here mentions the AI tutor, the "plan written by Claude", the downloadable course app or the PDF book.** The site only shows the AI features when the AI key is set in production, and the app and book are sent by hand today. If you add the first two later, mark them `[CONFIRM: AI key live in production]` until you've checked.

### 2.4 Images (brand style)

**Make one avatar file and use it everywhere.** 1080 × 1080 px PNG. Fill it with the site's logo tile gradient: `#7A5AF8` → `#6938EF` → `#4A1FB8`, top left to bottom right. Centre the white four-point sparkle mark from the site logo. Keep the mark inside the middle 60%, so the circle crop on every platform keeps it whole. No words: text can't be read at 98 to 110 px. No face is assumed. If you later choose a face photo, use it on a violet background and change it everywhere on the same day.

**Banners use one layout.** The background is ink `#0C0A1D` or royal violet `#6938EF`. The headline is "Learn AI. Implement AI. Grow with AI." in Geist SemiBold, white, with "Grow with AI." in Instrument Serif italic, gold `#FEC84B`. The second line is in Geist, and `principeai.com` goes on the last line. Use gold text on royal violet only at headline size (contrast is about 4:1). Behind smaller gold text, use deep violet `#4A1FB8` or ink.

**In Canva:** the free Brand Kit holds 3 colours: use `#6938EF`, `#FDB022` and `#0C0A1D`. Geist and Instrument Serif are free Google Fonts. If Canva doesn't list them, uploading fonts needs Canva Pro (reported). Free stand-ins: Inter for Geist, and DM Serif Display or Playfair Display Italic for Instrument Serif.

### 2.5 Schedulers

Connect each profile to a scheduler only after it's set up. The free default: Meta Business Suite for Facebook and Instagram, TikTok Studio, YouTube Studio and LinkedIn's own scheduler, plus Buffer Free for X, Threads and Bluesky (its 3 free channels) and Pinterest's own scheduler for Pins (Metricool Free also covers Pinterest, Threads and Bluesky, but can't post to X). The upgrade: Postiz (once it's connected, Claude can schedule posts through it) plus Canva Pro.

### 2.6 Account security

- Sign up with `principeconsults@gmail.com`, or with a domain mailbox such as `social@principeai.com` if you set one up. Use the same address everywhere so recovery emails all land in one place.
- Secure `principeconsults@gmail.com` (or the domain mailbox) first: every platform recovers to it. Turn on two-factor login with an authenticator app and save its recovery codes in a password manager.
- Turn on two-factor login with an authenticator app on every account. Save the recovery codes in a password manager.
- By L-13 (Wed Oct 28), add a trusted person as a second admin on the Meta business portfolio (which holds the Facebook Page and Instagram) and on the LinkedIn Page. If there's nobody, keep a printed copy of every recovery code somewhere safe.
- New business Pages get fake "your Page will be disabled" or "verify your account" messages. Treat them as scams: don't click their links or reply. Check Account Status or the Support Inbox inside the app instead.
- If an account is restricted or a post is removed: appeal inside the app, note it in your log, and don't open a replacement account to get around it.
- Write each handle and profile URL into the checklist in section 3 as you go. Section 7 needs them.
