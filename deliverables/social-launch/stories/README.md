## 2. Posting on Instagram

1. Add the frames to your Story in the order above, one set per day. Viewers can hold a frame to read it, so don't add extra text.
2. On the frames with a gold button (ST-05, ST-06, ST-16), add a **link sticker** with the link from section 4. Put it in the empty space just under the gold button, where the arrow points. Set the sticker text to the words in section 4.
3. Keep every sticker (link, poll, music) off the text. The top 250 px and bottom 300 px of each frame have no text, so Instagram's own buttons never cover any.
4. Save the recruiting set to a **"Join the team" Highlight** so it stays on your profile. Highlights count as profile links, so swap in the Highlight link from section 4, which uses `utm_medium=bio`. Leave the launch set out of Highlights: the kit's evergreen Highlights do that job ([05](../05-instagram-pinterest-facebook.md), 2.4).

**Launch day:** the calendar's Day 1 Story (VC-16, L+0 · Tue Nov 10 · 9:30 ET) can use ST-01 as its no-face first frame, ST-02 as frame 2 and ST-05 as frame 4, with VC-16's own sticker link.

## 3. Posting on Snapchat

1. Save the PNGs to your phone. In Snapchat, open **Memories → Camera Roll**, select the frames in order and send them to **My Story** (or your **Public Story** if you have a public profile).
2. Before sending ST-05, ST-06 and ST-16, tap the **paperclip (link)** tool in the editor and paste the Snapchat link from section 4. Snapchat shows the link under the Snap, where the arrow on the art points.
3. Stories disappear after 24 hours. With a public profile, save the recruiting set to your profile so it stays.

## 5. For sales agents

Agents post the **`launch-for-agents/`** set with **their own link**, so the sale is credited to them:

- **Their link:** the page address plus `?ref=` and their code, e.g. `https://principeai.com/free-guide?ref=THEIRCODE` on ST-05 and `https://principeai.com/assessment?ref=THEIRCODE` on ST-06. All their links are in the agent portal toolkit (`/agent/toolkit`).
- **Keep the `#ad` strip.** Don't crop, cover or sticker over it. The FTC requires the disclosure to be clear and up front, and the sales-team terms require it too.
- **No income or results claims** in anything they add (no "I made $…", no "you'll earn…").
- Share the folder with agents however suits you, for example a shared Google Drive folder.

The recruiting set isn't for agents to post: agents earn only on their own sales, never on recruiting.

## 6. What's on the art, and when to update it

Every fact on the frames comes from the site, and the frames avoid anything that changes often:

| On the art | Comes from | Update the art if you change |
|---|---|---|
| 20% / 25% / 30%, 5+ and 10+ sales a month, keep your level through the next month | Admin → Sales Team → Program (the defaults) | The levels |
| Paid twice a month, after a 30-day refund window | Admin → Sales Team → Program | The payout schedule or hold |
| No fees, single-level, commission-only, independent contractor, 18+ in the US, about 5 minutes to apply | `/sales-team` and `/sales-team/terms` | The terms |
| Course names and levels | Admin → Courses | A course name |
| 50 prompts, 7-day plan, about 10 minutes a day; 3-minute assessment | `/free-guide`, `/assessment` | The kit or the assessment |

On purpose, there are **no prices** (they change; check them on the site), **no earnings examples** (an income claim needs proof of typical results), **no client results** and **no AI tool logos**.

## 7. Editing and re-rendering

The frames are HTML: edit the words in [source/stories.html](source/stories.html), then from the repo root run:

```bash
node deliverables/social-launch/stories/source/render.mjs
```

That rewrites every PNG (Stories, `video-frames/`, `feed/`) and `overview.png`. Then rebuild the video and the TikTok JPEGs with `bash deliverables/social-launch/stories/source/make-reel.sh` (needs `ffmpeg`). It uses the repo's Playwright. If Playwright's own Chromium isn't installed, set `CHROMIUM_PATH` to a Chromium or Chrome binary. Fonts come from `scripts/course-kit/fonts/`. To preview the agent versions in a browser, add `#agent` to the file's address. Keep all text inside the safe area, which leaves the top 250 px and the bottom 300 px clear.
